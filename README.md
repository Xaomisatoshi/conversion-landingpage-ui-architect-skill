# Conversion Landingpage & UI Architect

Dieser Skill ist für deutschsprachige Conversion-, Landingpage- und UI-Aufgaben ausgelegt.

## Verwendung

Typische Aufrufe:

- „Erstelle eine Landingpage für mein SaaS-Angebot.“
- „Überarbeite diese Sales Page für höhere Conversion.“
- „Schreibe Hero, Benefits, Proof und CTA.“
- „Entwickle eine interaktive Landingpage-Struktur.“
- „Prüfe diese UI auf Conversion-Friktion.“
- „Erstelle A/B-Test-Hypothesen für die Seite.“

## Sprachregel

Input und Output werden auf Deutsch geführt.
